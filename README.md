# introds-group09-flight-delays

## Dataset

This repo does not store the raw datasets. Data comes from the
[nycflights13](https://github.com/tidyverse/nycflights13) package.

| # | Table    | Source |
|---|----------|--------|
| 1 | airlines | [airlines.csv](https://github.com/tidyverse/nycflights13/blob/main/data-raw/airlines.csv) |
| 2 | airports | [airports.csv](https://github.com/tidyverse/nycflights13/blob/main/data-raw/airports.csv) |
| 3 | flights  | [flights.R](https://github.com/tidyverse/nycflights13/blob/main/data-raw/flights.R) (generation script) |
| 4 | planes   | [planes.csv](https://github.com/tidyverse/nycflights13/blob/main/data-raw/planes.csv) |
| 5 | weather  | [weather.csv](https://github.com/tidyverse/nycflights13/blob/main/data-raw/weather.csv) |

Place the downloaded files in the `data/` folder.
