# Data source record

## Dataset

- Name: nycflights13 — NYC departures in 2013.
- Source: https://github.com/tidyverse/nycflights13
- Publisher: Hadley Wickham / tidyverse.
- Original flight records: US Bureau of Transportation Statistics.
- Original retrieval date: 21 October 2026.
- Dataset licence: CC0.

## Tables used

| Table | Rows | Columns |
|---|---:|---:|
| flights | 336,776 | 19 |
| airlines | 16 | 2 |

The notebook combines the tables using a validated many-to-one
left join on carrier. The merged table contains 336,776 rows
and 20 columns before further transformations.

## Data access and environment

- Python package: nycflights13==0.0.3.
- Python version used for the current notebook: 3.12.10.
- Installed libraries and versions: requirements.txt.

## File generation

The raw CSV files are regenerated by the notebook from
nycflights13==0.0.3.

CSV byte sizes and checksums may vary with export settings
and line endings. Earlier checksums have been removed because
they do not match the current generated files.

## Limitations

The records describe NYC departures in 2013 and do not establish
current airline performance or the causes of delays.
Missing arrival outcomes are not treated as zero delay.
